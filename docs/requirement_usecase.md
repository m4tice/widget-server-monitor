# Use cases requirements

## Description

A widget that provides status of servers (URLs) whether they are active (green) or not (red).

## Target OSes:
1. Windows 11
2. MacOS

# Features
- The widget shall be small, clean and minimal so that it does not obstruct main activities
- The widget transparency is 70-80% and minimized when not hovered.
- The widget transparency is 100% and shall be expaned when hovered.
- The widget can be opened via shortcut combination (Windows + any unused key).
- The widget shall optionally provide a switch so that it's intergrated together with Windows's widgets.
- The widget shall provide a setting button to open a setting menu.
- The widget setting menu shall provide options for add, modify, delete servers setup.

## Target environments
1. Company's laptop with restricted environment.
2. Home PC.
